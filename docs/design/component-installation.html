Installation

For React apps with Tailwind CSS 4.

For Expo SDK 55 or later.

Add a components.json to your app first, as the Expo guide shows.

Proposed command. The full payload URL needs no registries mapping. It works once each item at /r and /r/native is published self-contained, with its whole file closure and packages. Today's payloads still name @glassyui/… dependencies, which fail without a mapping. Package manager: one choice for every command, npm by default, remembered in this browser.

1Install the packages

2Add the files to components/glassyui

Keep the lib and styles folders, since the files import each other by relative path. If your @/ alias points at src, use src/components/glassyui.

Where the mock's data comes from

  • Name, category, description, usage and API: the Glass Button entry in src/components/docs/component-docs-data.ts; the component count is that file's 36 entries.
  • React files and packages: the closure of glass-button in registry.json (Glass Button and Glass Provider), with file text from public/r/glass-button.json and public/r/glass-provider.json.
  • React Native files and packages: the closure of glass-button in registry-native.json (Glass Button, Glass Provider, Glass Surface), with file text from public/r/native/.
  • React Native usage: fixtures/expo-consumer/usage/glass-button.tsx. Runners: the existing Getting Started copy (npx, pnpm dlx, yarn dlx, bunx --bun).
  • Expo SDK and development-build lines: the Expo guide. Hero copy: src/app/page.tsx. Mark: public/brand/glassyui-logo-compact.svg.
