# Security policy

## Reporting a vulnerability

Report vulnerabilities privately to
[support@glassyui.com](mailto:support@glassyui.com). Include the affected
component or website route, the source commit, and steps to reproduce the issue.
Do not send credentials or private user data.

Do not post exploit details in a public issue.

For non-sensitive bugs, use the
[project issue tracker](https://github.com/alexburlis/glassyui/issues).
