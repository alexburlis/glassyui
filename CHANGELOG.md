# Changelog

## 0.1.0

Initial source distribution of Glassy UI under MIT.

- 36 React components, distributed through a source-copy registry.
- 29 Expo registry items, with usage examples and a clean-consumer fixture.
- A CSS theme and two drop-in component sets for stock shadcn/ui apps.
- Interactive documentation, guides, preference controls and a live keynote.
- Reproducible registry generation, clean consumer installs and browser checks.
- External links and a public teaser for the separate Glassy UI Pro preorder
  app.

Package dependencies retain their own licenses; see
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
